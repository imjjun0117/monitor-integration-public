# 화면 및 계정·권한 관리

## 화면 구성

Shadcn Admin의 MIT 버튼·입력·테이블·대화상자 컴포넌트를 공통 UI에 적용한다.
관제 화면은 네이비 배경과 청록·보라·초록 계열 차트를 사용한다.
버튼·선택 메뉴·입력 포커스는 보라색을 공통 강조 색상으로 사용한다.
지표와 수집 방식은 기존 동작을 유지한다.
컴포넌트 출처와 라이선스는 `agent/frontend/THIRD_PARTY_NOTICES.md`에 기록한다.

우측 사용자 드롭다운의 화면 모드 전환 항목으로 라이트·다크 모드를 전환한다. 선택값은 브라우저의
`monitoring.theme` 항목에 저장하며 새로고침과 로그인 화면에도 적용한다.
차트 선·축·툴팁 색상도 화면 모드에 맞춰 바꾼다.

설정 메뉴는 클릭하면 하위 메뉴가 펼쳐지고 다시 클릭하면 접힌다.
설정 화면에 직접 접속하면 자동으로 펼친다. 닫힌 하위 메뉴는 키보드로 접근할 수 없다.
움직임 최소화 설정을 사용하는 브라우저에서는 전환 애니메이션을 줄인다.

설정 도구 버튼은 데스크톱에서 32px, 입력·드롭다운은 34px 높이를 사용한다.
목록 수정·삭제는 텍스트형 버튼으로 표시한다. 등록·수정 모달은 라벨 왼쪽·입력 오른쪽으로
정렬하며 하단은 취소 → 저장 순서다. 모달 바깥 클릭으로 입력 내용을 닫지 않는다.
역할 모달은 480px, 다른 설정 모달은 600px 너비를 기준으로 화면 크기에 맞춰 줄인다.
모바일에서는 입력·버튼·선택 항목을 44px로 확보하고 라벨을 입력 위에 표시한다.
닫기는 22px 아이콘과 44px 클릭 영역을 유지한다.

## 관리 순서

1. 관리자가 **설정 → 역할·권한 관리 → 역할 등록**에서 역할 ID·이름·설명·기준 권한·사용 여부를 등록한다.
2. 왼쪽 역할을 선택하고 오른쪽 **메뉴 권한**에서 조회·변경 권한을 저장한다. 신규 역할은 모든 메뉴 접근이 차단된 상태로 시작한다.
3. **사용자 배정** 탭에서 계정을 배정한다. 사용자 관리의 역할 선택에서도 동일한 역할 목록을 사용한다.
4. **사용자 관리**에서 계정과 담당 프로젝트를 지정한다.
5. **설정 → 메뉴 관리**에서 메뉴 이름·순서·사용 여부를 설정한다.
6. 설정 하위 메뉴는 모니터링 설정과 접근·권한 관리로 구분한다. 상단 설정 탭은 표시하지 않는다.

기존 CMS의 사용자 → 역할 → 메뉴 권한 흐름을 참고했다. 해당 CMS 코드를 복사하거나 수정하지 않는다.

## 저장 및 적용

- 계정: PostgreSQL `app_users`, 비밀번호는 BCrypt 해시 저장.
- 담당 프로젝트: `user_project_access`.
- 메뉴: `app_menus`.
- 역할: `app_roles`. 역할별 메뉴 권한: `role_menu_permissions`.
- 메뉴·권한 변경 이력: `audit_log`.

등록된 5개 화면의 메뉴 이름·순서·사용 여부를 관리한다. 연결 경로는 고정한다.
관리자·운영자·조회자는 보호된 기본 역할이다. 사용자 정의 역할은 조회용 또는 운영용 기준으로 등록하며 기준 권한은 등록 후 변경할 수 없다.
왼쪽 목록에서 역할을 선택하고 오른쪽 메뉴 권한·사용자 배정을 관리한다. 사용자 수를 누르면 배정 탭으로 이동한다.
사용자는 하나의 역할을 가지며 다른 역할에 배정하면 이동한다. 배정 해제 시 기본 조회자로 돌아가고 담당 프로젝트는 유지한다.
기본 조회자는 배정 해제로 역할을 없앨 수 없으며 관리자 회수는 사용자 관리에서 기존 보호 규칙을 적용한다.
미사용 역할은 기존 로그인과 신규 로그인을 차단한다. 배정된 사용자가 있는 역할은 삭제할 수 없다.
조회자는 변경 권한을 받을 수 없다. 운영자는 계정·메뉴·권한·감사 이력 관리에 접근할 수 없다.
관리자 권한과 설정 메뉴는 잠기지 않도록 보호한다.

권한은 서버에서 매 요청마다 DB 기준으로 확인하며 기존 프로젝트 접근 범위와 함께 적용한다.
브라우저는 로그인 정보를 주기적으로 확인해 메뉴와 버튼을 갱신한다.
권한을 변경해도 이미 처리된 작업은 취소되지 않으며 이후 요청부터 제한된다.

## 로컬 실행

`scripts/dev-up.ps1` 실행 후 `http://127.0.0.1:8080`에 접속한다.
프런트 개발 화면은 `http://127.0.0.1:5173`이다.
Flyway V16이 메뉴·권한, V17이 사용자 정의 역할 테이블을 추가한다. 기존 계정·역할·프로젝트 접근 범위는 유지한다.
