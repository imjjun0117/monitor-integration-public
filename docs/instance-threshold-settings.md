# 인스턴스 임계치 관리

1. **임계치 관리** 메뉴에서 프로젝트 → 인스턴스를 선택한다.
2. 해당 서버에 등록한 임계치만 목록에 표시한다. 등록 이력이 없다면 빈 목록으로 시작한다.
3. **추가**를 누르고 항목을 선택한다. CPU·RAM·JVM Heap·디스크·DB Pool은 %, API 응답시간은 초로 입력한다. **SSL 인증서 만료**는 이 프로젝트의 인증서 대상을 선택하고 남은 일수로 입력한다. 경고 30일·위험 7일처럼 경고 일수가 위험 일수 이상이어야 하며, 일수는 0 이상의 정수다.
4. 경고·위험 기준과 이 항목의 **알림 이메일**을 입력한 뒤 **등록**한다. 이메일은 쉼표로 구분해 최대 10개 입력한다. 비워두면 수신자 미설정으로 저장하며 다른 항목의 이메일을 상속하지 않는다.
5. 등록한 항목은 목록에서 수정·삭제한다. 삭제는 확인 창에서 확정한다. 같은 서버에 같은 항목을 중복 등록할 수 없다.

프로젝트 → 인스턴스 상세의 **임계치 관리** 탭에서도 같은 목록을 사용한다. 프로젝트를 변경하면 이전 인스턴스 선택과 입력 화면을 초기화한다. 다른 서버의 설정은 변경하지 않는다.

목록에는 명시적으로 등록한 인스턴스 기준만 표시한다. 기존 등록 기준은 유지한다. 미등록·삭제한 항목은 기존 프로젝트·전역·내장 기준으로 판정하며, 목록이 비었다고 자원 수집이나 공통 상태 판정이 중단되지는 않는다. 기존 인증서 기준도 유지한다.

자동 메일 발송은 아직 연결되지 않았다. 현재는 항목별 수신자 저장·조회 기능이다. 기존 권한·CSRF·감사 이력·트랜잭션 검증을 유지한다.

중앙 Agent와 프론트엔드·OpenAPI를 반영한다. 기존 담당자 테이블을 재사용하므로 SSL 대상 연결을 위한 Flyway `V21__instance_certificate_thresholds.sql`을 적용한다. Collector JAR·Configurer 변경은 필요 없다.

SSL 기준은 선택한 인증서 하나에 연결한다. 같은 인증서를 다른 인스턴스에 중복 연결하지 않는다. 인증서 대상 관리에서 등록한 사용 중인 대상만 선택할 수 있다. 저장 즉시 최근 검사 결과의 상태를 새 일수 기준으로 재판정하며, 이후 TLS 검사에도 같은 기준을 적용한다. SSL 기준 삭제 시 대상 연결을 해제하고 기존 프로젝트·전역 기준으로 돌아간다. 대상 자체와 검사 기록은 삭제하지 않는다.
