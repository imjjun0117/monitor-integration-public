# 사용자 권한과 변경 이력

중앙 서버의 설정 → 사용자 관리에서 계정을 만들고 프로젝트를 지정합니다.

| 권한 | 범위 |
| --- | --- |
| 관리자 | 전체 프로젝트, 계정 및 권한 관리, 삭제, 변경 이력 조회 |
| 운영자 | 지정 프로젝트 조회, 설정 변경과 점검 실행. 프로젝트 및 계정 관리와 영구 삭제는 제한 |
| 조회자 | 지정 프로젝트 조회만 가능 |

서버 로그 원문은 관리자와 담당 운영자에게만 허용하며 조회자는 접근할 수 없습니다. 로그 설정과 조회 시작 이력을 기록하고 원문은 저장하지 않습니다. 반영 방법은 [실시간 로그](realtime-logs.md)를 참고하세요.

프로젝트를 지정하지 않은 운영자·조회자는 프로젝트 데이터에 접근할 수 없습니다. 서버에서도 권한을 검사하므로 주소를 직접 입력해도 제한됩니다. 권한 변경은 다음 API 요청부터 적용되고, 계정 비활성화 및 비밀번호 변경은 기존 로그인도 종료합니다. 자신의 관리자 권한을 없애거나 마지막 관리자를 비활성화할 수 없습니다.

설정 → 변경 이력에서 사용자·프로젝트별로 누가 언제 어떤 값을 변경했는지 확인합니다. 프로젝트, 인스턴스, 점검, 임계값, 인증서, 계정, 프로젝트 접근 권한 변경을 기록합니다. 변경과 이력 저장은 같은 트랜잭션으로 처리합니다. 이력을 저장하지 못하면 설정 변경도 취소합니다.

비밀번호, 토큰, 서비스 인증 정보 원문은 저장하지 않습니다. 변경 여부만 기록합니다. 수동 점검의 접수 이력은 실행 요청의 접수를 뜻하며, 실제 점검 결과는 점검 결과 화면에서 확인합니다. 자동 수집 결과는 설정 변경 이력에 포함하지 않습니다. 기능 적용 이전의 변경 이력은 없습니다.

DB 마이그레이션 V14는 기존 계정과 프로젝트를 유지하면서 권한과 이력 테이블을 추가합니다. 대상 서버의 모니터링 JAR나 자바 코드를 교체할 필요는 없습니다.
