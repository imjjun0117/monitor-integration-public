# 샘플 프로젝트 안전 파일럿

실제 샘플 프로젝트 저장소 위치가 제공되지 않아 이 저장소 밖의 파일은 수정하지 않았습니다. 이 폴더는 검토 후 사람이 적용할 수 있는 예시입니다.

1. `monitor-agent.jar`를 WAR의 `WEB-INF/lib`에 포함합니다.
2. `web.xml.fragment`를 기존 `web.xml`에 병합합니다. 기존 JSP는 유지합니다.
3. 토큰은 32바이트 이상 난수로 만들고 외부 보안 설정에서 주입합니다.
4. 모든 점검은 기본 비활성화입니다. 읽기 전용임을 확인한 항목만 하나씩 켭니다.
5. 기존 결과와 신규 결과를 JSON `results` 배열로 내보내 `node tools/shadow-compare.mjs legacy.json agent.json result.json`으로 비교합니다.
6. 24시간 동안 불일치를 기록하고 원인을 해결한 뒤에만 전환을 검토합니다.

현재 실제 서버 설치와 24시간 shadow 비교는 수행하지 않았습니다. 실제 URL·키·응답 본문을 비교 파일에 넣지 마십시오.
